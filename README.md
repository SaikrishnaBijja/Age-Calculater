# Age Calculater

A simple web tool to calculate a person’s age given a birth date.  
This is implemented as a small static web application (HTML, CSS, JavaScript).

## Features

- Input a birth date (day, month, year).  
- Calculate current age in years, months, days.  
- Friendly UI with responsive design.  
- Easy to understand and use.
